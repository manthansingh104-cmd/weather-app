# 🌦️ Real-Time Weather Insights

A modern, responsive weather application that provides real-time weather information, forecasts, air quality data, and interactive weather visuals. Built with React, TypeScript, Tailwind CSS, and modern web technologies.

🔗 **Live Demo:** https://weather-app-rose-eight-26.vercel.app/

---

## ✨ Features

### 🌍 Real-Time Weather

* Search weather by city name
* Get weather using your current location
* Live temperature, humidity, wind speed, pressure, and visibility data

### 🌤️ Forecasts

* 5-day weather forecast
* Hourly weather forecast
* Dynamic weather icons and conditions

### 🌅 Interactive Weather UI

* Animated weather backgrounds
* Sunrise and sunset visualization
* Smooth animations using Framer Motion
* Glassmorphism design

### 🎤 Voice Weather Search

* Search cities using your voice
* Web Speech API integration
* Microphone support detection

### 👏 Clap-to-Search

* Hands-free voice activation
* Clap detection using microphone input

### 🌫️ Air Quality Information

* Real-time air quality data
* UV index information
* Detailed weather insights

### ⭐ User Features

* Recent searches saved locally
* Favorite cities
* Temperature unit switching
* Wind speed unit switching

### 📱 Responsive Design

* Optimized for:

  * Desktop
  * Tablets
  * Mobile phones

## 🚀 Installation & Setup

Clone the repository:

```bash
git clone https://github.com/your-username/your-repository-name.git
```

Go into the project folder:

```bash
cd your-repository-name
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```
http://localhost:5173
```

---

## 🔑 Environment Variables

Create a `.env` file:

```env
VITE_WEATHER_API_KEY=your_api_key_here
```

Add your weather API key before running the project.
